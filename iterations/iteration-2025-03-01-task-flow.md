## 1. 需求分析

### 1.1 核心需求

1. **创建任务按钮**
   - 按钮名称保持"创建任务"
   - 点击后不被禁用，可连续创建多个任务
   - 创建任务后不自动运行（除非勾选"自动执行"）

2. **自动执行选项**
   - 选项名称为"自动执行"
   - 勾选后：任务创建后自动执行扫描→预览→执行
   - 不勾选：任务只创建，需手动点击运行

3. **任务操作按钮**
   - 根据任务当前状态显示对应操作
   - 每个阶段完成后显示"下一步"按钮
   - 运行中可终止

### 1.2 任务状态流转

```
创建任务
    │
    ▼
CREATED (已创建)
    │ 点击"开始扫描" 或 自动执行
    ▼
SCANNING (扫描中) ──终止──▶ CANCELLED
    │ 扫描完成
    ▼
SCANNED (已扫描)
    │ 点击"开始预览" 或 自动执行
    ▼
PREVIEWING (预览中) ──终止──▶ CANCELLED
    │ 预览完成
    ▼
PREVIEWED (已预览)
    │ 点击"开始执行" 或 自动执行
    ▼
EXECUTING (执行中) ──终止──▶ CANCELLED
    │ 执行完成
    ▼
COMPLETED (已完成)
```

### 1.3 操作按钮设计

| 任务状态 | 显示按钮 | 说明 |
|---------|---------|------|
| CREATED | 开始扫描 | 开始扫描阶段 |
| SCANNING | 终止 | 终止当前操作 |
| SCANNED | 开始预览 | 开始预览阶段 |
| PREVIEWING | 终止 | 终止当前操作 |
| PREVIEWED | 开始执行 | 开始执行阶段 |
| EXECUTING | 终止 | 终止当前操作 |
| COMPLETED | 重新执行 | 重新执行整个流程 |
| FAILED | 重试 | 重试当前阶段 |
| CANCELLED | 重新运行 | 从头开始运行 |
