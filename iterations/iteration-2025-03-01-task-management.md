## 1. 现状分析

### 1.1 当前问题

1. **创建任务按钮问题**
   - 按钮名称为"创建任务"（正确）
   - 但按钮在某些状态下会被禁用（错误）
   - 用户期望：创建任务按钮应始终可用，允许连续创建多个任务

2. **任务列表显示问题**
   - 单个任务失败会导致整个任务列表显示"分析流水线失败"
   - 任务列表应该独立显示，不受单个任务状态影响

3. **任务阶段管理不清晰**
   - 用户无法直观看到当前任务处于哪个阶段
   - 阶段之间的流转关系不明确
   - 缺少阶段级别的操作控制

4. **交互体验混乱**
   - 任务操作按钮分布不合理
   - 缺少阶段进度可视化
   - 操作反馈不明确

### 1.2 当前任务状态定义

```
CREATED      - 已创建（初始状态）
SCANNING     - 扫描中
SCANNED      - 已扫描
PREVIEWING   - 预览中
PREVIEWED    - 已预览
EXECUTING    - 执行中
COMPLETED    - 已完成
FAILED       - 失败
CANCELLED    - 已取消
```

### 1.3 当前阶段定义

```
SCAN      - 扫描阶段
PREVIEW   - 预览阶段
EXECUTION - 执行阶段
```

## 2. 设计目标

### 2.1 核心原则

1. **任务独立性**：单个任务的失败不影响其他任务的显示和操作
2. **阶段可视化**：清晰展示任务的三个阶段及当前所处阶段
3. **操作可达性**：每个阶段都有明确的操作入口和状态反馈
4. **流程可控性**：用户可以随时终止、重试、跳过某个阶段

### 2.2 任务状态机设计

```
                    ┌─────────────┐
                    │   CREATED   │
                    │   (已创建)   │
                    └──────┬──────┘
                           │ 点击"开始扫描"
                           ▼
                    ┌─────────────┐     ┌─────────────┐
         ┌─────────│  SCANNING   │────▶│   FAILED    │
         │         │   (扫描中)   │     │   (失败)    │
         │         └──────┬──────┘     └─────────────┘
         │                │ 扫描完成              ▲
         │                ▼                      │
         │         ┌─────────────┐              │
         │         │   SCANNED   │──────────────┘
         │         │   (已扫描)   │  点击"重新扫描"
         │         └──────┬──────┘
         │                │ 点击"开始预览"
         │                ▼
         │         ┌─────────────┐     ┌─────────────┐
         ├─────────│  PREVIEWING │────▶│   FAILED    │
         │         │   (预览中)   │     └──────┬──────┘
         │         └──────┬──────┘            │
         │                │ 预览完成            │
         │                ▼                   │
         │         ┌─────────────┐            │
         │         │  PREVIEWED  │────────────┘
         │         │   (已预览)   │ 点击"重新预览"
         │         └──────┬──────┘
         │                │ 点击"开始执行"
         │                ▼
         │         ┌─────────────┐     ┌─────────────┐
         └─────────│  EXECUTING  │────▶│   FAILED    │
                   │   (执行中)   │     └──────┬──────┘
                   └──────┬──────┘            │
                          │ 执行完成            │
                          ▼                   │
                   ┌─────────────┐            │
                   │  COMPLETED  │────────────┘
                   │   (已完成)   │ 点击"重新执行"
                   └─────────────┘

         任意运行中状态 ──────▶ CANCELLED (点击"终止")
```

### 2.3 阶段可视化设计

每个任务卡片显示三个阶段进度条：

```
[扫描] ──▶ [预览] ──▶ [执行]
  ✓          ✓          ○
 (完成)    (完成)    (未开始)
```

阶段状态标识：
- `○` - 未开始/等待中
- `◐` - 进行中
- `✓` - 已完成
- `✗` - 失败
- `⊘` - 已取消

### 2.4 操作按钮设计

根据任务当前状态显示对应操作：

| 当前状态 | 可用操作 |
|---------|---------|
| CREATED | 开始扫描 |
| SCANNING | 终止 |
| SCANNED | 开始预览、重新扫描 |
| PREVIEWING | 终止 |
| PREVIEWED | 开始执行、重新预览、重新扫描 |
| EXECUTING | 终止 |
| COMPLETED | 重新执行、重新预览、重新扫描 |
| FAILED | 重试当前阶段、重新扫描 |
| CANCELLED | 重新扫描 |
