# 端到端测试计划

## 测试概述

本文档描述了Music Manager Plus系统的端到端测试计划，用于验证系统各个功能模块的正确性和稳定性。

## 测试环境

- **前端**: http://localhost:8081
- **后端**: http://localhost:8080
- **数据库**: SQLite (data/music_manager.db)
- **日志目录**: backend/logs/

## 测试用例

### 1. 任务管理功能测试

#### 1.1 创建预览任务
**测试步骤**:
1. 打开浏览器访问 http://localhost:8081
2. 切换到"组合配置"页面
3. 添加源目录（例如：/tmp/test_music）
4. 配置插件流水线
5. 切换到"预览执行"页面
6. 点击"预览"按钮
7. 等待任务创建完成

**预期结果**:
- 任务列表中显示新的预览任务
- 任务状态为"SCANNING"或"PREVIEWING"
- 任务状态会自动更新（通过WebSocket）
- 任务完成后状态变为"PREVIEWED"

**验证点**:
- ✓ 任务列表显示新任务
- ✓ 任务状态正确显示
- ✓ WebSocket实时更新工作正常
- ✓ 任务完成后状态正确

#### 1.2 查看任务详情
**测试步骤**:
1. 在任务列表中点击一个任务
2. 查看任务详情页面

**预期结果**:
- 显示任务的基本信息（任务ID、状态、开始时间等）
- 显示配置快照
- 显示扫描结果
- 显示预览结果
- 显示执行结果（如果已执行）

**验证点**:
- ✓ 任务基本信息正确显示
- ✓ 各阶段结果正确显示
- ✓ UI布局合理，信息清晰

#### 1.3 执行任务
**测试步骤**:
1. 选择一个状态为"PREVIEWED"的任务
2. 点击"执行"按钮
3. 确认执行操作
4. 等待任务执行完成

**预期结果**:
- 任务状态变为"EXECUTING"
- 任务执行完成后状态变为"COMPLETED"
- 可以查看执行结果

**验证点**:
- ✓ 任务执行成功
- ✓ 任务状态正确更新
- ✓ 执行结果正确显示

#### 1.4 删除单个任务
