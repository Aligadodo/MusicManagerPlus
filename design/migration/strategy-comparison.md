# 核心文件管理策略功能对比分析

## 概述

本文档对比老架构和新架构中核心文件管理策略的功能实现，识别缺失的功能点，为后续迁移提供指导。

## 1. 文件归类策略 (FileCollectionStrategy)

### 老架构功能

#### 核心功能
- 基于文件名相似度进行文件聚类
- 生成合集文件夹并移动文件
- 支持关键词过滤
- 支持添加到现有合集
- 智能避免重复处理

#### 配置参数
- `slSimilarityThreshold`: 相似度阈值滑块（0.0-1.0）
- `txtCollectionSuffix`: 合集文件夹格式（如：【合集】）
- `cbTargetType`: 目标类型选择（仅文件/仅文件夹/全部）
- `cbNamingStrategy`: 命名策略选择（简洁风格/精确风格/选取模板）
- `txtMustContainKeywords`: 必须包含的关键词
- `txtMustNotContainKeywords`: 不能包含的关键词

#### 核心算法
- `FilenameNormalizer`: 文件名标准化
- `TextSimilarityCalculator`: 文本相似度计算
- `FileClusteringAlgorithm`: 文件聚类算法
- `CollectionDeterminationAlgorithm`: 合集判定算法

#### 命名策略
- 简洁风格：保留核心关键词，去除年份、文件格式等冗余信息
- 精确风格：保留年份、专辑类型等重要信息，只去除CD序号、文件格式等差异信息
- 选取模板：按名称排序后取中间的一个，只做最简单的干扰文本去除

### 新架构实现 (FileCollectionPlugin)

#### 已实现功能
- 基本文件收集到目标目录
- 递归收集子目录
- 覆盖已存在文件选项
- 保留目录结构选项

#### 缺失功能
1. **相似度计算**
   - 缺少文件名相似度计算
   - 缺少相似度阈值配置
   - 缺少基于相似度的文件聚类

2. **合集管理**
   - 缺少合集文件夹后缀配置
   - 缺少合集名称生成逻辑
   - 缺少添加到现有合集功能
   - 缺少合集判定算法

3. **命名策略**
   - 缺少简洁风格命名
   - 缺少精确风格命名
   - 缺少模板命名

4. **关键词过滤**
   - 缺少必须包含关键词过滤
   - 缺少不能包含关键词过滤

5. **智能处理**
   - 缺少避免重复处理机制
   - 缺少检查文件是否已在合集文件夹中
   - 缺少检查是否大部分文件已属于同一合集

### 迁移建议

#### 优先级：高

1. **实现相似度计算模块**
   - 创建 `FilenameNormalizer` 类
   - 创建 `TextSimilarityCalculator` 类
   - 实现基于Levenshtein距离的相似度计算

2. **实现文件聚类算法**
   - 创建 `FileClusteringAlgorithm` 类
   - 实现基于相似度阈值的聚类逻辑
   - 实现合集名称生成（基于最长公共前缀）

3. **添加配置参数**
   - 添加相似度阈值参数（0.0-1.0）
   - 添加合集文件夹后缀参数
   - 添加命名策略选择参数
   - 添加关键词过滤参数

4. **实现智能处理**
   - 添加父目录处理状态跟踪
   - 实现添加到现有合集逻辑
   - 实现避免重复处理检查
