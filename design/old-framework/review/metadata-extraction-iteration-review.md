## 技术亮点

### 1. 多艺术家检测

**实现方式**：
```java
// 检查艺术家部分是否包含空格分隔的多个艺术家
if (artistPart.contains(" ")) {
    String[] artistCandidates = artistPart.split("\\s+");
    // 检查是否是常见的多艺术家模式
    boolean isMultiArtist = true;
    for (String artist : artistCandidates) {
        if (artist.length() > 10 || artist.matches(".*\\d{4}.*")) {
            isMultiArtist = false;
            break;
        }
    }
    if (isMultiArtist) {
        meta.artist = String.join(", ", artistCandidates);
    }
}
```

**特点**：
- 智能判断是否为多艺术家
- 避免误判单个长艺术家名
- 使用逗号分隔多个艺术家

### 2. 目录结构解析

**实现方式**：
- 支持多种目录命名格式
- 跳过中间目录（如"Split - WAV"）
- 从父目录和祖父目录提取信息
- 处理编号目录（如"0 - 中文歌手"）

**特点**：
- 灵活处理各种目录结构
- 智能跳过无关目录
- 多层级信息提取

### 3. 特殊字符处理

**实现方式**：

- 处理日文假名、希腊字母等
- 正确处理各种符号

**特点**：

- 灵活的字符处理

### 4. 年份提取

## 问题与挑战

### 1. 文件名格式多样性

**挑战**：
- 用户文件名格式千差万别
- 没有统一的命名规范
- 特殊字符和符号使用频繁

**解决方案**：
- 支持多种常见格式
- 智能识别文件名模式
- 灵活的正则表达式匹配

### 2. 目录结构复杂性

**挑战**：
- 目录层级深浅不一
- 目录命名格式多样
- 中间目录干扰信息提取

**解决方案**：
- 多层级信息提取
- 智能跳过无关目录
- 支持多种目录命名格式

### 3. 多艺术家识别

**挑战**：
- 艺术家名长度不一
- 分隔符多样（空格、逗号、&等）
- 容易误判单个长艺术家名

**解决方案**：
- 智能判断艺术家数量
- 基于艺术家名长度判断
- 支持多种分隔符

### 4. 特殊字符处理

**挑战**：
- Unicode字符编码复杂
- 不同语言字符差异大
- 特殊符号处理困难

**解决方案**：
- 完整的Unicode支持
- 灵活的字符处理
- 正确的编码处理
