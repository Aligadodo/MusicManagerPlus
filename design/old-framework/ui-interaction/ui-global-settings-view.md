# GlobalSettingsView 设计文档

## 概述

**功能**: 全局设置视图，配置全局扫描和过滤参数

**实现**: IAutoReloadAble

**设计模式**: MVC模式

## 核心职责

1. 配置扫描模式
2. 配置目录层级
3. 配置文件类型过滤
4. 配置扫描过滤器

## 核心组件

### 1. 扫描模式配置

- **cbRecursionMode**: 扫描模式下拉框
- **spRecursionDepth**: 目录层级选择器
- **spMinRecursionDepth**: 最小目录层级
- **spMaxRecursionDepth**: 最大目录层级
- **recursionDepthRangeBox**: 目录层级范围容器

### 2. 文件类型过滤

- **scanFilterListView**: 扫描过滤器列表
- **scanFilterInput**: 扫描过滤器输入框
- **scanFilterList**: 扫描过滤器列表数据

### 3. 文件类型管理

- **fileTypeManager**: AdvancedFileTypeManager
- 管理文件类型
- 提供文件类型过滤功能

## 界面布局

### 1. 扫描模式配置

**配置项**:
- 扫描模式选择
- 目录层级配置
- 目录层级范围配置

### 2. 文件类型过滤

**配置项**:
- 文件类型列表
- 文件类型输入
- 文件类型管理

## 核心方法

### 1. initControls()
**功能**: 初始化UI控件

**处理流程**:
1. 创建扫描模式下拉框
2. 创建目录层级选择器
3. 创建文件类型过滤器
4. 设置默认值
5. 绑定事件监听

### 2. buildUI()
**功能**: 构建UI界面

**处理流程**:
1. 创建主容器
2. 创建扫描模式配置
3. 创建文件类型过滤
4. 设置布局

### 3. updateScanModeVisibility()
**功能**: 更新扫描模式可见性

**处理流程**:
1. 获取当前扫描模式
2. 根据模式显示/隐藏控件
3. 更新UI状态

## 扫描模式

### 1. 全部文件

**描述**: 扫描所有层级的文件

**配置**:
- 无需配置目录层级
- 扫描所有子目录

### 2. 当前目录

**描述**: 只扫描当前目录

**配置**:
- 不扫描子目录
- 只扫描当前目录的文件

### 3. 指定目录层级

**描述**: 扫描到指定的层级

**配置**:
- 设置目录层级
- 扫描到指定层级的所有文件

### 4. 目录层级范围

**描述**: 扫描指定范围内的层级

**配置**:
- 设置最小层级
- 设置最大层级
- 扫描范围内的所有文件

## 常见问题

### Q1: 如何配置扫描模式？

**步骤**:
1. 选择扫描模式
2. 配置目录层级
3. 确认配置

### Q2: 如何添加文件类型过滤？

**步骤**:
1. 在输入框中输入文件类型
2. 点击添加按钮
3. 文件类型添加到列表

### Q3: 如何删除文件类型过滤？

**步骤**:
1. 选中要删除的文件类型
2. 点击删除按钮
3. 文件类型从列表中移除

GlobalSettingsView提供了完整的全局设置功能，具有以下特点：

1. **灵活的扫描模式**: 支持多种扫描模式
2. **精确的层级控制**: 支持目录层级配置
3. **强大的过滤功能**: 支持文件类型过滤

通过GlobalSettingsView，用户可以方便地配置全局扫描和过滤参数，提高文件管理效率。
