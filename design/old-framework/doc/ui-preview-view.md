# PreviewView 设计文档

## 概述

**功能**: 预览执行视图，显示文件变更预览和执行进度

**实现**: IAutoReloadAble

**设计模式**: MVC模式

## 核心职责

1. 显示文件变更预览
2. 提供筛选和搜索功能
3. 显示执行进度和统计
4. 控制任务执行和停止

## 核心组件

### 1. 预览表格

- **previewTable**: TreeTableView<ChangeRecord>
- 显示文件变更信息
- 支持展开/折叠
- 支持选择操作

### 2. 筛选组件

- **txtSearchFilter**: 搜索框
- **cbStatusFilter**: 状态筛选
- **cbOperationTypeFilter**: 操作类型筛选
- **chkHideUnchanged**: 隐藏未变更文件

### 3. 进度显示

- **mainProgressBar**: 主进度条
- **runningLabel**: 运行状态标签
- **statsLabel**: 统计信息标签
- **rootPathProgressBars**: 根路径进度条
- **rootPathProgressLabels**: 根路径进度标签

### 4. 控制按钮

- **btnExecuteSelected**: 执行选中项
- **btnDeleteOriginal**: 删除源文件
- **btnDeleteTarget**: 删除目标文件
- **chkSelectAll**: 全选复选框

### 5. 线程配置

- **spPreviewThreads**: 预览线程数
- **spExecutionThreads**: 执行线程数
- **cbThreadPoolMode**: 线程池模式选择
- **rootPathSpinners**: 根路径线程数配置

**工具栏组件**:

## 核心方法

### 1. buildUI()
**功能**: 构建UI界面

**处理流程**:
1. 创建主容器
2. 创建工具栏
3. 创建预览表格
4. 创建进度区域
5. 创建线程配置

### 2. updatePreviewTable()
**功能**: 更新预览表格

**处理流程**:
1. 清空表格
2. 加载变更记录
3. 应用筛选条件
4. 更新表格显示

### 3. applyFilters()
**功能**: 应用筛选条件

**处理流程**:
1. 获取筛选条件
2. 过滤变更记录
3. 更新表格显示

### 4. updateProgress()
**功能**: 更新进度显示

**处理流程**:
1. 更新主进度条
2. 更新运行状态
3. 更新统计信息
4. 更新根路径进度

### 5. updateRootPathThreadConfigUI()
**功能**: 更新根路径线程配置UI

**处理流程**:
1. 清空现有配置
2. 为每个根路径创建配置
3. 设置默认值
4. 绑定事件监听

## 交互设计

### 1. 预览操作

**预览流程**:
1. 用户在ComposeView配置流水线
2. 点击"预览"按钮
3. 系统分析文件
4. PreviewView显示预览结果

### 2. 筛选操作

**筛选功能**:
- 搜索框：按文件名搜索
- 状态筛选：按状态筛选
- 操作类型筛选：按操作类型筛选
- 隐藏未变更：隐藏未变更的文件

### 3. 执行操作

**执行流程**:
1. 用户选择要执行的项
2. 点击"执行"按钮
3. 系统执行流水线
4. 更新进度和状态

### 4. 删除操作

**删除功能**:
- 删除源文件：删除原始文件
- 删除目标文件：删除目标文件
- 支持批量删除

## 数据绑定

### 1. 预览数据绑定

**绑定方式**:
- TreeTableView绑定到ChangeRecord列表
- 自动同步数据变化
- 支持实时更新

### 2. 筛选条件绑定

**绑定方式**:
- 搜索框绑定到搜索条件
- 下拉框绑定到筛选条件
- 复选框绑定到选项

### 3. 进度绑定

**绑定方式**:
- 进度条绑定到任务进度
- 标签绑定到状态信息
- 自动更新显示

## 性能优化

### 1. 虚拟化

**实现方式**:
- 使用TreeTableView虚拟化
- 只渲染可见行
- 减少内存占用

### 2. 分页加载

**实现方式**:
- 支持分页显示
- 按需加载数据
- 提高响应速度

### 3. 异步更新

**实现方式**:
- 使用Platform.runLater更新UI
- 避免阻塞UI线程
- 提高用户体验

### 4. 自动刷新

**实现方式**:
- 定时自动刷新
- 10秒刷新一次
- 显示最新状态

## 线程管理

### 1. 线程池模式

**模式选择**:
- 共享模式：所有根路径共享线程池
- 独立模式：每个根路径独立线程池

### 2. 线程数配置

**配置项**:
- 预览线程数：控制预览时的线程数
- 执行线程数：控制执行时的线程数
- 根路径线程数：每个根路径的线程数

### 3. 动态调整

**调整机制**:
- 监听线程数变化
- 实时调整线程池大小
- 优化任务执行效率

## 注意事项

### 1. 性能考虑

**注意事项**:
- 大数据量时使用虚拟化
- 避免频繁更新UI
- 使用异步处理

### 2. 线程安全

**注意事项**:
- UI更新在JavaFX线程
- 数据访问使用同步机制
- 避免死锁

### 3. 内存管理

**注意事项**:
- 及时清理不再使用的数据
- 避免内存泄漏
- 优化数据结构
