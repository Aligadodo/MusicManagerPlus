# MetadataScraperStrategy 设计文档

## 概述

**功能**: 元数据抓取策略，从在线源抓取音频文件的元数据

**继承**: IAppStrategy

**设计模式**: 策略模式、工厂模式

## 核心职责

1. 从多个在线源抓取元数据
2. 支持iTunes、MusicBrainz、Last.fm、网易云音乐、咪咕音乐等
3. 下载歌词文件
4. 下载封面图片
5. 写入音频文件元数据
6. 支持元数据缓存
7. 支持智能匹配
8. 支持批量抓取

## 核心组件

### 1. UI组件

#### 数据源选择
- `cbDataSource`: 数据源选择
  - iTunes（默认）
  - MusicBrainz
  - Last.fm
  - 网易云音乐
  - 咪咕音乐

#### 抓取选项
- `chkDownloadLyrics`: 下载歌词
- `chkDownloadCover`: 下载封面
- `chkOverwriteMetadata`: 覆盖现有元数据
- `chkUseCache`: 使用缓存
- `chkSmartMatch`: 智能匹配

#### 高级选项
- `spCacheDays`: 缓存天数（默认：7天）
- `txtCustomKeywords`: 自定义关键词
- `chkBatchMode`: 批量模式

### 2. 运行时参数

- `pDataSource`: 数据源
- `pDownloadLyrics`: 是否下载歌词
- `pDownloadCover`: 是否下载封面
- `pOverwriteMetadata`: 是否覆盖元数据
- `pUseCache`: 是否使用缓存
- `pSmartMatch`: 是否智能匹配
- `pCacheDays`: 缓存天数
- `pCustomKeywords`: 自定义关键词
- `pBatchMode`: 是否批量模式

### 3. 抓取组件

- `LyricsManager`: 歌词管理器
- `LyricsProvider`: 歌词提供者接口
- `NeteaseLyricsProvider`: 网易云歌词提供者
- `MiguLyricsProvider`: 咪咕歌词提供者

## 核心方法

### 1. analyze(ChangeRecord rec, List<ChangeRecord> inputRecords, List<File> rootDirs)
**功能**: 分析文件并生成抓取记录

**处理流程**:
1. 检查文件是否为音频文件
2. 提取文件名中的歌曲信息
3. 搜索在线数据源
4. 生成抓取记录

### 2. execute(ChangeRecord rec)
**功能**: 执行元数据抓取和写入

**处理流程**:
1. 检查操作类型是否为SCRAPE
2. 从在线源抓取元数据
3. 下载歌词文件（如果启用）
4. 下载封面图片（如果启用）
5. 写入音频文件元数据

## 设计要点

### 1. 数据源选择

**网易云音乐**:
- 数据丰富
- 覆盖面广
- 歌词质量高

**咪咕音乐**:
- 版权歌曲多
- 音质较好
- 歌词准确

### 2. 元数据字段

**基本信息**:
- 标题（Title）
- 艺术家（Artist）
- 专辑（Album）
- 年份（Year）
- 音轨编号（Track）
- 流派（Genre）

**扩展信息**:
- 作词（Lyricist）
- 作曲（Composer）
- 编曲（Arranger）
- 评论（Comment）

### 3. 歌词下载

**歌词格式**:
- LRC格式
- UTF-8编码
- 时间轴信息

**文件命名**:
- 与音频文件同名
- .lrc扩展名
- 同目录存储

### 4. 封面下载

**封面格式**:
- JPEG格式
- 推荐尺寸：500x500
- 高质量图片

**嵌入方式**:
- 嵌入到音频文件
- 同时保存为独立文件
- 文件命名：cover.jpg

### 5. 元数据写入

**写入方式**:
- 使用JAudioTagger库
- 支持多种音频格式
- 保留原有元数据（可选）

**支持格式**:
- MP3（ID3v2）
- FLAC（Vorbis注释）
- WAV（INFO标签）
- AAC（MP4标签）

## 注意事项

### 1. 网络连接

**要求**:
- 需要稳定的网络连接
- 可能需要代理
- 遵守API限制

**错误处理**:
- 网络超时重试
- API限流处理
- 错误日志记录

### 2. 版权合规

**注意事项**:
- 仅用于个人学习
- 不得用于商业用途
- 遵守数据源的使用条款

### 3. 元数据覆盖

**覆盖策略**:
- 默认不覆盖现有元数据
- 可选择强制覆盖
- 支持选择性覆盖

**风险**:
- 可能丢失原有元数据
- 建议先备份
- 确认无误后再覆盖

### 4. 歌词准确性

**影响因素**:
- 数据源质量
- 歌曲信息匹配度
- 歌词版本差异

**建议**:
- 检查歌词准确性
- 手动校对关键歌词
- 使用多个数据源对比

### 5. 封面质量

**质量标准**:
- 推荐尺寸：500x500或更高
- 文件大小：建议<1MB
- 图片格式：JPEG

**处理方式**:
- 自动选择最佳封面
- 支持手动指定封面
- 支持封面替换

## 常见问题

### Q1: 为什么某些歌曲无法抓取？

**可能原因**:
1. 网络连接问题
2. 歌曲信息不匹配
3. 数据源没有该歌曲
4. API限流

**解决方案**:
1. 检查网络连接
2. 确认歌曲信息准确
3. 尝试其他数据源
4. 稍后重试

### Q2: 如何提高抓取准确性？

**优化建议**:
1. 规范文件命名
2. 提供准确的艺术家和歌曲名
3. 使用多个数据源对比
4. 手动校对抓取结果

### Q3: 歌词下载失败怎么办？

**解决方案**:
1. 检查网络连接
2. 尝试其他数据源
3. 手动下载歌词
4. 检查歌词格式

### Q4: 封面下载失败怎么办？

**解决方案**:
1. 检查网络连接
2. 尝试其他数据源
3. 手动指定封面
4. 检查封面格式

## 最佳实践

### 1. 处理流程

**推荐顺序**:
1. 使用CueSplitterStrategy分轨
2. 使用AudioConverterStrategy转换
3. 使用TrackNumberStrategy编号
4. 使用MetadataScraperStrategy抓取元数据

### 2. 参数配置

**标准抓取**:
- 数据源：网易云音乐
- 下载歌词：启用
- 下载封面：启用
- 覆盖元数据：禁用

**完整抓取**:
- 数据源：网易云音乐
- 下载歌词：启用
- 下载封面：启用
- 覆盖元数据：启用

**仅抓取歌词**:
- 数据源：网易云音乐
- 下载歌词：启用
- 下载封面：禁用
- 覆盖元数据：禁用

### 3. 文件命名规范

**推荐格式**:
- 艺术家 - 歌曲名称
- 专辑名称 - 音轨编号 - 歌曲名称
- 歌曲名称 - 艺术家

**避免**:
- 过多的特殊字符
- 不一致的命名格式
- 缺少关键信息

### 4. 备份策略

**备份建议**:
1. 抓取前备份原始文件
2. 保留原始元数据记录
3. 确认无误后再删除备份

## 总结

MetadataScraperStrategy提供了完整的元数据抓取功能，具有以下特点：

1. **多数据源**: 支持网易云音乐、咪咕音乐等
2. **功能丰富**: 支持元数据、歌词、封面抓取
3. **格式支持**: 支持多种音频格式
4. **灵活配置**: 丰富的抓取选项
5. **易于使用**: 直观的配置界面

通过MetadataScraperStrategy，用户可以快速为音频文件补充完整的元数据信息，提高音乐文件的组织性和可读性。
