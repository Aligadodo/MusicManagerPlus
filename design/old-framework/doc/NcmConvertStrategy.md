# NcmConvertStrategy 设计文档

## 概述

**功能**: NCM格式转换策略，将NCM加密音频文件转换为标准音频格式

**继承**: NcmBaseStrategy

**设计模式**: 继承扩展模式

## 核心职责

1. NCM文件解密
2. 转换为标准音频格式
3. 元数据提取和保留
4. 批量转换处理

## 核心组件

### 1. NCM解密组件

- `NcmDump`: NCM文件解析和转储
- `NcmKey`: NCM密钥管理
- `CacheFileInfo`: 缓存文件信息

### 2. 元数据处理

- `MetaData`: 元数据模型
- `FileNameExtractor`: 文件名提取器
- `IdxFileParser`: IDX文件解析器

### 3. API组件

- `NeteaseApiClient`: 网易云API客户端

## 核心方法

### 1. analyze(ChangeRecord rec, List<ChangeRecord> inputRecords, List<File> rootDirs)
**功能**: 分析NCM文件并生成转换记录

**处理流程**:
1. 检查文件是否为NCM格式
2. 解析NCM文件
3. 提取元数据
4. 生成输出路径
5. 生成转换记录

### 2. execute(ChangeRecord rec)
**功能**: 执行NCM转换操作

**处理流程**:
1. 解析NCM文件
2. 解密音频数据
3. 转换为标准格式
4. 写入元数据
5. 保存输出文件

## 常见问题

### Q1: 为什么某些NCM文件无法转换？

**可能原因**:
1. NCM文件损坏
2. 密钥获取失败
3. 加密算法不支持
4. 网络连接问题

**解决方案**:
1. 检查文件完整性
2. 更新密钥
3. 检查网络连接
4. 查看错误日志

### Q2: 转换速度慢怎么办？

**优化建议**:
1. 使用多线程处理
2. 启用缓存机制
3. 减少同时处理的文件数

### Q3: 元数据丢失怎么办？

**解决方案**:
1. 检查元数据处理选项
2. 从原始NCM文件重新提取
3. 手动添加元数据

### Q4: 如何批量转换？

**步骤**:
1. 选择源目录
2. 配置转换参数
3. 执行批量转换
4. 查看转换结果

NcmConvertStrategy提供了完整的NCM转换功能，具有以下特点：

通过NcmConvertStrategy，用户可以快速将NCM加密文件转换为标准音频格式，便于播放和管理。
