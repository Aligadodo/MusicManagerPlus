# AppearanceManager 设计文档

## 概述

**功能**: 界面设置管理器，提供主题配置、颜色设置、字体设置等功能

**设计模式**: 单例模式

## 核心职责

1. 主题预设管理
2. 颜色配置管理
3. 字体配置管理
4. 透明度配置管理
5. 背景图片管理

## 核心组件

### 1. 主题配置

- **currentTheme**: ThemeConfig
- 当前主题配置
- 存储所有主题参数

### 2. 背景组件

- **backgroundImageView**: ImageView
- 背景图片显示
- 支持自定义背景

- **backgroundOverlay**: Region
- 背景遮罩
- 实现毛玻璃效果

### 3. 管理器

- **themeManager**: ThemeManager
- 主题管理器
- 管理主题切换

- **templateManager**: StyleTemplateManager
- 样式模板管理器
- 管理样式模板

### 4. UI组件

- **tpAppearance**: JFXTabPane
- 界面设置标签页
- 组织不同设置类别

- **finalPresetTab**: Tab
- 主题预设选项卡
- 用于更新预设列表

## 核心方法

### 1. getAppearanceSettingsContent()
**功能**: 获取界面设置内容

**处理流程**:
1. 创建主容器
2. 创建标签页
3. 添加各个设置标签页
4. 返回内容节点

### 2. createPresetTabContent()
**功能**: 创建主题预设标签页内容

**处理流程**:
1. 创建预设主题列表
2. 添加预设主题
3. 创建主题预览
4. 添加应用按钮

### 3. createColorTabContent()
**功能**: 创建颜色设置标签页内容

**处理流程**:
1. 创建颜色选择器
2. 绑定颜色到主题配置
3. 创建颜色预览
4. 添加保存按钮

### 4. createFontTabContent()
**功能**: 创建字体设置标签页内容

**处理流程**:
1. 创建字体选择器
2. 创建字体大小选择器
3. 绑定字体到主题配置
4. 添加保存按钮

### 5. createOpacityTabContent()
**功能**: 创建透明度设置标签页内容

**处理流程**:
1. 创建透明度滑块
2. 绑定透明度到主题配置
3. 创建透明度预览
4. 添加保存按钮

### 6. createBackgroundTabContent()
**功能**: 创建背景设置标签页内容

**处理流程**:
1. 创建背景图片选择器
2. 创建背景图片预览
3. 创建缩放模式选择器
4. 添加保存按钮

## 总结

AppearanceManager提供了完整的界面设置功能，具有以下特点：

1. **丰富的主题**: 支持多种预设主题
2. **灵活的配置**: 支持自定义颜色、字体、透明度
3. **实时预览**: 实时预览配置效果
4. **易于使用**: 直观的配置界面
5. **配置持久化**: 自动保存配置

通过AppearanceManager，用户可以方便地配置界面外观，打造个性化的用户界面。
