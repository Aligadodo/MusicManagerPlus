# AdvancedRenameStrategy 设计文档

## 概述

**功能**: 高级重命名策略，基于规则对文件进行批量重命名

**继承**: IAppStrategy

**设计模式**: 策略模式、规则引擎模式

## 核心职责

1. 基于规则进行文件重命名
2. 支持多个条件组合
3. 支持多种重命名动作
4. 支持规则优先级管理
5. 支持规则导入导出

## 核心组件

### 1. UI组件

#### 规则管理
- `lvRules`: 规则列表
- `btnAddRule`: 添加规则按钮
- `btnRemoveRule`: 删除规则按钮
- `btnMoveUp`: 上移规则按钮
- `btnMoveDown`: 下移规则按钮

### 2. 运行时参数

- `pRules`: 重命名规则列表

### 3. 规则模型

- `RenameRule`: 重命名规则
- `RenameMode`: 重命名模式
- `RenameActionType`: 重命名动作类型
- `RuleCondition`: 规则条件

## 核心方法

### 1. analyze(ChangeRecord rec, List<ChangeRecord> inputRecords, List<File> rootDirs)
**功能**: 分析文件并生成重命名记录

**处理流程**:
1. 遍历所有规则
2. 检查文件是否满足规则条件
3. 应用重命名动作
4. 生成新的文件名
5. 检查目标文件是否存在
6. 生成ChangeRecord

### 2. execute(ChangeRecord rec)
**功能**: 执行文件重命名操作

**处理流程**:
1. 检查操作类型是否为RENAME
2. 重命名文件
3. 更新相关元数据

## 设计要点

### 1. 规则引擎

**规则结构**:
- 条件（Conditions）
- 动作（Actions）
- 优先级（Priority）

**条件类型**:
- 文件名匹配
- 文件大小范围
- 文件修改日期
- 文件扩展名
- 正则表达式

**动作类型**:
- 替换文本
- 添加前缀
- 添加后缀
- 删除文本
- 大小写转换
- 正则替换

### 2. 规则优先级

**执行顺序**:
- 按规则列表顺序执行
- 第一个匹配的规则生效
- 后续规则不再执行

**管理方式**:
- 上移/下移调整优先级
- 删除规则
- 添加规则到指定位置

### 3. 条件组合

**逻辑关系**:
- AND: 所有条件都满足
- OR: 任一条件满足
- NOT: 条件不满足

**组合方式**:
- 支持多条件组合
- 支持嵌套条件
- 支持自定义逻辑

### 4. 动作执行

**执行方式**:
- 按动作列表顺序执行
- 支持多个动作组合
- 支持动作参数

**参数类型**:
- 文本参数
- 正则表达式
- 大小写选项
- 位置参数

## 注意事项

### 1. 规则冲突

**冲突场景**:
- 多个规则匹配同一文件
- 动作产生冲突结果

**解决方式**:
- 按优先级执行
- 第一个匹配的规则生效
- 后续规则不再执行

### 2. 文件名冲突

**检查机制**:
- 检查目标文件是否存在
- 检查大小写不敏感
- 检查简体中文匹配

**处理方式**:
- 跳过重命名
- 或覆盖现有文件

### 3. 特殊字符处理

**处理方式**:
- 自动过滤非法字符
- 保留合法特殊字符
- 支持自定义过滤规则

### 4. 大小写处理

**处理选项**:
- 保持原样
- 全部大写
- 全部小写
- 首字母大写
- 标题大小写

### 5. 正则表达式

**支持**:
- 标准正则表达式
- 捕获组
- 替换引用

**注意事项**:
- 转义特殊字符
- 测试正则表达式
- 避免贪婪匹配

## 常见问题

### Q1: 为什么某些文件没有被重命名？

**可能原因**:
1. 不满足任何规则条件
2. 目标文件已存在且未启用覆盖
3. 规则优先级问题

**解决方案**:
1. 检查规则条件
2. 启用覆盖选项
3. 调整规则优先级

### Q2: 如何创建复杂的重命名规则？

**解决方案**:
1. 使用多个条件组合
2. 使用多个动作组合
3. 使用正则表达式
4. 调整规则优先级

### Q3: 如何批量导入规则？

**解决方案**:
1. 导出规则为JSON文件
2. 编辑JSON文件
3. 导入规则文件

### Q4: 如何调试规则？

**解决方案**:
1. 使用预览功能
2. 逐个测试规则
3. 检查规则日志
4. 调整规则参数

## 总结

AdvancedRenameStrategy提供了强大的规则重命名功能，具有以下特点：

1. **规则引擎**: 灵活的规则匹配和执行
2. **条件组合**: 支持多条件组合
3. **动作丰富**: 支持多种重命名动作
4. **优先级管理**: 支持规则优先级调整
5. **易于扩展**: 支持自定义条件和动作

通过AdvancedRenameStrategy，用户可以创建复杂的重命名规则，实现批量文件重命名的自动化。
