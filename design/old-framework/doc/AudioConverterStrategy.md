# AudioConverterStrategy 设计文档

## 概述

**功能**: 音频格式转换策略，支持多种音频格式的高品质转换

**继承**: AbstractFfmpegStrategy

**设计模式**: 继承扩展模式

**版本**: v19.6 CD Mode Fix

## 核心职责

1. 音频文件格式转换
2. 智能跳过CD镜像文件
3. 文件存在性检查
4. 目标文件名格式化

## 核心组件

### 1. 新增UI组件

#### 智能跳过选项
- `chkSkipCueTracks`: 当音频文件大于100MB且同目录下有.cue文件时，跳过处理
- 默认开启
- 避免重复处理CD镜像文件

### 2. 运行时参数

- `pSkipCueTracks`: 是否启用智能跳过

## 核心方法

### 1. analyze(ChangeRecord rec, List<ChangeRecord> inputRecords, List<File> rootDirs)
**功能**: 分析文件并生成转换记录

**处理流程**:
1. 检查文件是否为音频文件
2. 智能跳过检查（如果启用）
3. 生成转换参数
4. 格式化目标文件名
5. 检查目标文件是否存在
6. 生成ChangeRecord

**智能跳过逻辑**:
```java
if (pSkipCueTracks) {
    // 检查文件大小是否大于100MB
    if (actualFile.length() > 100 * 1024 * 1024) {
        // 检查同目录下是否存在.cue文件
        File[] files = parentDir.listFiles((dir, filename) -> 
            filename.toLowerCase().endsWith(".cue"));
        if (files != null && files.length > 0) {
            // 跳过处理
            return Collections.emptyList();
        }
    }
}
```

### 2. execute(ChangeRecord rec)
**功能**: 执行音频转换

**处理流程**:
1. 检查操作类型是否为CONVERT
2. 调用父类的execute方法执行转换

## 设计要点

### 1. 智能跳过机制

**目的**: 避免重复处理CD镜像文件

**判断条件**:
- 文件大小大于100MB
- 同目录下存在.cue文件

**应用场景**:
- 用户已经使用CueSplitterStrategy处理过CD镜像
- 避免对大文件进行不必要的转换
- 提高处理效率

### 2. 文件存在性检查

**检查参数**:
- 大小写不敏感
- 简体中文匹配
- 去除首尾空格

**检查逻辑**:
1. 检查目标路径下是否存在同名文件
2. 如果启用doubleCheck，检查双重路径
3. 如果存在且未启用覆盖，跳过处理

### 3. 文件名格式化

**格式化操作**:
- 转换为简体中文
- 去除首尾空格

**触发条件**:
- autoFormatFilename参数为true（默认）

### 4. CD模式参数锁定

**优化点**:
- 修复了Lambda表达式中变量非effectively final的编译错误
- 完善了CD模式的参数锁定逻辑，防止被通用参数覆盖

**锁定逻辑**:
- 选择"WAV (CD标准)"时，自动禁用采样率和声道选择
- 避免用户误操作导致CD刻录失败

## 注意事项

### 1. 文件大小阈值

**当前设置**: 100MB

**考虑因素**:
- CD镜像文件通常较大
- 避免误判普通大文件
- 可根据实际情况调整

### 2. CUE文件检测

**检测范围**: 同目录下所有.cue文件

**注意事项**:
- 大小写不敏感
- 只检查文件扩展名
- 不检查CUE文件内容

### 3. 覆盖控制

**默认行为**: 不覆盖已存在的文件

**覆盖条件**:
- 用户显式勾选"强制覆盖"选项
- 目标文件不存在

### 4. 文件名编码

**编码处理**:
- 自动转换为简体中文
- 去除首尾空格
- 保持文件名规范性

### 5. 操作类型检查

**检查逻辑**: 只处理OperationType.CONVERT类型的记录

**目的**: 避免误处理其他类型的操作

## 常见问题

### Q1: 为什么某些大文件被跳过？

**原因**: 启用了智能跳过选项，且文件满足以下条件：
1. 文件大小大于100MB
2. 同目录下存在.cue文件

**解决方案**:
1. 禁用智能跳过选项
2. 或删除同目录下的.cue文件

### Q2: 如何处理CD镜像文件？

**推荐流程**:
1. 先使用CueSplitterStrategy分轨
2. 再使用AudioConverterStrategy转换音轨文件
3. 启用智能跳过选项避免重复处理

### Q3: 文件名出现乱码怎么办？

**解决方案**:
1. 启用自动格式化选项
2. 系统会自动转换为简体中文
3. 去除首尾空格

### Q4: 如何批量转换音频文件？

**步骤**:
1. 选择源目录
2. 配置转换参数
3. 启用智能跳过（如果需要）
4. 执行批量转换

## 最佳实践

### 1. CD处理流程

**推荐顺序**:
1. 使用CueSplitterStrategy分轨
2. 使用AudioConverterStrategy转换音轨
3. 使用TrackNumberStrategy编号
4. 使用MetadataScraperStrategy抓取元数据

### 2. 参数配置

**CD刻录**:
- 格式：WAV (CD标准)
- 智能跳过：启用
- 自动格式化：启用

**无损存储**:
- 格式：FLAC
- 智能跳过：禁用
- 自动格式化：启用

**移动设备**:
- 格式：MP3
- 比特率：256kbps
- 智能跳过：禁用

### 3. 性能优化

**大批量转换**:
- 启用临时文件缓存
- 适当增加FFmpeg线程数
- 使用镜像路径暂存

**格式一致转换**:
- 利用流拷贝模式
- 速度提升百倍
- 内存占用近乎0

### 4. 文件管理

**避免覆盖**:
- 默认不勾选覆盖选项
- 检查目标文件是否存在
- 使用文件存在性检查

**规范命名**:
- 启用自动格式化
- 转换为简体中文
- 去除首尾空格

## 总结

AudioConverterStrategy提供了完整的音频转换功能，具有以下特点：

1. **智能跳过**: 自动识别CD镜像文件，避免重复处理
2. **格式丰富**: 支持多种音频格式转换
3. **参数灵活**: 丰富的转换参数配置
4. **文件安全**: 完善的文件存在性检查
5. **用户友好**: 自动格式化、悬浮提示

通过继承AbstractFfmpegStrategy，AudioConverterStrategy获得了强大的FFmpeg集成能力，同时添加了智能跳过等特定功能，为用户提供了高效、安全的音频转换体验。
