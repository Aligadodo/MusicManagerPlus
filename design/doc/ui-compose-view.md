# ComposeView 设计文档

## 概述

**功能**: 任务编排视图，提供流水线配置界面

**实现**: IAutoReloadAble

**设计模式**: MVC模式

## 核心职责

1. 源目录选择和管理
2. 流水线策略配置
3. 策略参数编辑
4. 前置条件配置

## 核心组件

### 1. 源目录管理

- **sourceListView**: 显示源目录列表
- 支持拖拽添加目录
- 支持按钮添加目录
- 支持删除目录

### 2. 流水线配置

- **pipelineListView**: 显示流水线策略列表
- 支持添加策略
- 支持删除策略
- 支持调整策略顺序
- 支持编辑策略参数

### 3. 参数配置

- **configContainer**: 策略参数配置容器
- 动态加载策略配置界面
- 支持策略特定参数

### 4. 前置条件

- **tpFilters**: 前置条件面板
- 支持条件组合
- 支持条件编辑

## 界面布局

### 1. 三栏布局

**左栏 - Step1 选择目录**:
- 源目录列表
- 添加目录按钮
- 删除目录按钮

**中栏 - Step2 流水线配置**:
- 策略列表
- 添加策略按钮
- 删除策略按钮
- 上移/下移按钮

**右栏 - Step3 参数配置**:
- 策略参数配置
- 前置条件配置

### 2. 网格布局

**GridPane**:
- 3列布局
- 每列宽度：30%, 35%, 35%
- 自适应高度

## 核心方法

### 1. buildUI()
**功能**: 构建UI界面

**处理流程**:
1. 创建主容器
2. 创建网格布局
3. 添加三栏面板
4. 初始化组件状态

### 2. createLeftPanel()
**功能**: 创建左栏面板

**处理流程**:
1. 创建VBox面板
2. 创建源目录列表
3. 创建操作按钮
4. 设置拖拽支持

### 3. createMidPanel()
**功能**: 创建中栏面板

**处理流程**:
1. 创建VBox面板
2. 创建策略列表
3. 创建操作按钮
4. 设置拖拽支持

### 4. createRightPanel()
**功能**: 创建右栏面板

**处理流程**:
1. 创建VBox面板
2. 创建配置容器
3. 创建前置条件面板
4. 设置动态加载

### 5. refreshList()
**功能**: 刷新策略列表

**处理流程**:
1. 清空策略列表
2. 加载可用策略
3. 更新UI状态

## 交互设计

### 1. 源目录管理

**添加目录**:
- 点击"添加目录"按钮
- 弹出目录选择对话框
- 选择目录后添加到列表

**删除目录**:
- 选中目录
- 点击"删除目录"按钮
- 从列表中移除

**拖拽添加**:
- 拖拽文件夹到列表区域
- 自动添加到列表

### 2. 流水线配置

**添加策略**:
- 点击"添加策略"按钮
- 弹出策略选择对话框
- 选择策略后添加到列表

**删除策略**:
- 选中策略
- 点击"删除策略"按钮
- 从列表中移除

**调整顺序**:
- 选中策略
- 点击"上移"或"下移"按钮
- 调整策略顺序

### 3. 参数配置

**编辑参数**:
- 选中策略
- 右侧显示策略参数
- 修改参数值
- 自动保存配置

**配置前置条件**:
- 选中策略
- 展开"前置条件"面板
- 添加条件
- 配置条件参数

## 设计要点

### 1. 动态加载

**实现方式**:
- 根据选中的策略动态加载配置界面
- 通过策略的getConfigNode方法获取配置节点
- 动态更新配置容器

**优势**:
- 界面简洁
- 配置灵活
- 易于扩展

### 2. 拖拽支持

**实现方式**:
- 支持拖拽目录到列表
- 支持拖拽调整策略顺序
- 使用JavaFX拖拽API

**优势**:
- 操作便捷
- 用户体验好
- 提高效率

### 3. 参数验证

**实现方式**:
- 策略内部验证参数
- 显示错误提示
- 阻止无效配置

**优势**:
- 防止配置错误
- 提高可靠性
- 改善用户体验

## 常见问题

### Q1: 为什么某些策略无法添加？

**可能原因**:
1. 策略依赖未满足
2. 策略参数不完整
3. 策略与已有策略冲突

**解决方案**:
1. 检查策略依赖
2. 完善策略参数
3. 移除冲突策略

### Q2: 如何配置策略的前置条件？

**步骤**:
1. 选中策略
2. 展开"前置条件"面板
3. 添加条件
4. 配置条件参数

### Q3: 如何调整策略执行顺序？

**步骤**:
1. 选中策略
2. 点击"上移"或"下移"按钮
3. 调整到合适位置

## 总结

ComposeView提供了完整的任务编排功能，具有以下特点：

1. **直观的界面**: 三栏布局，清晰的功能分区
2. **灵活的配置**: 支持动态加载策略配置
3. **便捷的操作**: 支持拖拽、按钮等多种操作方式
4. **完善的验证**: 支持参数验证和前置条件
5. **易于扩展**: 模块化设计，易于添加新策略

通过ComposeView，用户可以轻松配置文件处理流水线，实现自动化的文件管理。
