# FileMigrateStrategy 设计文档

## 概述

**功能**: 文件迁移策略，将音频文件迁移到规范化的目录结构中

**继承**: IAppStrategy

**设计模式**: 策略模式

## 核心职责

1. 根据音频文件元数据生成目标目录结构
2. 将文件迁移到目标目录
3. 支持多种目录结构模板
4. 支持元数据验证
5. 支持播放列表生成
6. 支持目录结构保留

## 核心组件

### 1. UI组件

#### 目标目录
- `txtDestDir`: 目标根目录
- `btnBrowseDest`: 浏览目标目录

#### 目录结构模板
- `cbStructureTemplate`: 目录结构模板
  - 艺术家/专辑
  - 艺术家/专辑/年份
  - 艺术家/年份/专辑
  - 流派/艺术家/专辑
  - 自定义模板

#### 迁移选项
- `chkValidateMetadata`: 验证元数据完整性
- `chkOverwriteExisting`: 覆盖现有文件
- `chkPreserveTimestamp`: 保留时间戳
- `chkGeneratePlaylist`: 生成播放列表
- `chkKeepOriginalStructure`: 保留原始目录结构

#### 高级选项
- `txtCustomTemplate`: 自定义目录结构模板
- `cbPlaylistFormat`: 播放列表格式（M3U, PLS, WPL）

### 2. 运行时参数

- `pDestDir`: 目标根目录
- `pStructureTemplate`: 目录结构模板
- `pValidateMetadata`: 是否验证元数据
- `pOverwriteExisting`: 是否覆盖
- `pPreserveTimestamp`: 是否保留时间戳
- `pGeneratePlaylist`: 是否生成播放列表
- `pPlaylistFormat`: 播放列表格式
- `pKeepOriginalStructure`: 是否保留原始结构
- `pCustomTemplate`: 自定义模板

## 核心方法

### 1. analyze(ChangeRecord rec, List<ChangeRecord> inputRecords, List<File> rootDirs)
**功能**: 分析文件并生成迁移记录

**处理流程**:
1. 检查目标目录是否设置
2. 检查文件是否为音频文件
3. 提取文件元数据
4. 验证元数据完整性（如果启用）
5. 根据模板生成目标路径
6. 检查目标文件是否存在
7. 生成ChangeRecord

**目录结构生成**:
- 根据模板和元数据生成目录结构
- 支持多层嵌套
- 支持自定义模板

### 2. execute(ChangeRecord rec)
**功能**: 执行文件迁移操作

**处理流程**:
1. 检查操作类型是否为MOVE
2. 创建目标目录（如果不存在）
3. 复制/移动文件到目标位置
4. 保留时间戳（如果启用）
5. 更新播放列表（如果启用）
6. 删除原始文件（如果移动）

## 设计要点

### 1. 目录结构模板

**预设模板**:

1. **艺术家/专辑**
   - 示例：王菲/天空/
   - 适用于：标准音乐库结构

2. **艺术家/专辑/年份**
   - 示例：王菲/天空/1994/
   - 适用于：需要按年份组织的音乐库

3. **艺术家/年份/专辑**
   - 示例：王菲/1994/天空/
   - 适用于：按年份查看艺术家作品

4. **流派/艺术家/专辑**
   - 示例：流行/王菲/天空/
   - 适用于：按流派组织的音乐库

5. **自定义模板**
   - 支持占位符：{artist}, {album}, {year}, {genre}, {track}
   - 示例：{genre}/{artist}/{album}/{year}

### 2. 元数据验证

**验证规则**:
- 艺术家不能为空或"Unknown Artist"
- 专辑不能为空或"Unknown Album"
- 标题不能为空或"Unknown Title"

**处理方式**:
- 验证失败：跳过该文件
- 验证成功：继续处理

### 3. 文件操作

**操作模式**:
- **复制**: 保留原始文件
- **移动**: 删除原始文件

**选择依据**:
- 默认使用复制模式
- 移动模式需要用户确认

### 4. 时间戳保留

**保留内容**:
- 创建时间
- 修改时间
- 访问时间

**处理方式**:
- 使用Files.setLastModifiedTime()
- 需要管理员权限（某些系统）

### 5. 播放列表生成

**播放列表格式**:
- **M3U**: 最常用的播放列表格式
- **PLS**: Winamp播放列表格式
- **WPL**: Windows Media Player格式

**生成规则**:
- 按目录生成播放列表
- 按艺术家生成播放列表
- 按专辑生成播放列表
- 使用相对路径

### 6. 目录结构保留

**保留方式**:
- 保留原始目录层级
- 在目标目录中重建结构
- 适用于复杂目录结构

**示例**:
- 原始：Music/Artist/Album/Song.mp3
- 目标：Dest/Music/Artist/Album/Song.mp3

## 注意事项

### 1. 目标目录

**要求**:
- 必须设置目标目录
- 目标目录必须可写
- 建议使用绝对路径

**不支持**:
- 不存在的目录（自动创建）
- 只读目录
- 网络驱动器（可能）

### 2. 文件类型

**支持**: 音频文件（MP3, FLAC, WAV, AAC等）

**不支持**: 非音频文件

### 3. 元数据质量

**影响因素**:
- 元数据来源
- 元数据编辑工具
- 文件来源

**建议**:
- 使用MetadataScraperStrategy补充元数据
- 手动检查关键元数据
- 使用一致的元数据格式

### 4. 文件冲突

**处理方式**:
- 检查目标文件是否存在
- 如果存在且未启用覆盖，跳过处理
- 如果启用覆盖，覆盖现有文件

**风险**:
- 可能丢失现有文件
- 建议先备份
- 确认无误后再覆盖

### 5. 路径长度

**限制**:
- Windows：260字符
- Linux：4096字符

**建议**:
- 使用简洁的目录结构
- 避免过长的艺术家或专辑名
- 使用缩写或简称

### 6. 磁盘空间

**要求**:
- 目标磁盘有足够空间
- 考虑复制模式的空间需求

**检查**:
- 迁移前检查磁盘空间
- 警告空间不足

## 常见问题

### Q1: 为什么某些文件没有被迁移？

**可能原因**:
1. 目标目录未设置
2. 文件元数据不完整
3. 元数据验证失败
4. 目标文件已存在且未启用覆盖
5. 磁盘空间不足

**解决方案**:
1. 设置目标目录
2. 使用MetadataScraperStrategy补充元数据
3. 禁用元数据验证
4. 启用覆盖选项
5. 检查磁盘空间

### Q2: 如何自定义目录结构？

**解决方案**:
1. 选择"自定义模板"
2. 输入自定义目录结构
3. 使用占位符：{artist}, {album}, {year}, {genre}, {track}

**示例**:
- {artist}/{album}/{year}
- {genre}/{artist}/{album}
- {year}/{artist}/{album}

### Q3: 如何批量迁移多个文件？

**步骤**:
1. 选择源目录
2. 设置目标目录
3. 配置迁移参数
4. 选择目录结构模板
5. 执行批量迁移

### Q4: 迁移后如何恢复？

**解决方案**:
1. 使用复制模式（保留原始文件）
2. 使用备份恢复
3. 手动移动文件回原位置

## 最佳实践

### 1. 处理流程

**推荐顺序**:
1. 使用MetadataScraperStrategy补充元数据
2. 使用AlbumDirNormalizeStrategy规范化目录
3. 使用TrackNumberStrategy编号
4. 使用FileMigrateStrategy迁移文件

### 2. 参数配置

**标准迁移**:
- 目录结构：艺术家/专辑
- 验证元数据：启用
- 覆盖现有文件：禁用
- 保留时间戳：启用
- 生成播放列表：启用
- 播放列表格式：M3U
- 保留原始结构：禁用

**完整迁移**:
- 目录结构：艺术家/专辑/年份
- 验证元数据：启用
- 覆盖现有文件：启用
- 保留时间戳：启用
- 生成播放列表：启用
- 播放列表格式：M3U
- 保留原始结构：启用

**快速迁移**:
- 目录结构：艺术家/专辑
- 验证元数据：禁用
- 覆盖现有文件：启用
- 保留时间戳：禁用
- 生成播放列表：禁用
- 保留原始结构：禁用

### 3. 元数据准备

**推荐做法**:
1. 使用MetadataScraperStrategy补充元数据
2. 检查关键元数据字段
3. 统一艺术家和专辑名称
4. 确认年份信息准确

### 4. 备份策略

**备份建议**:
1. 迁移前备份原始文件
2. 使用复制模式（保留原始文件）
3. 确认无误后再删除原始文件
4. 使用版本控制管理备份

3. **安全可靠**: 支持复制/移动模式选择

5. **灵活配置**: 丰富的配置选项

通过FileMigrateStrategy，用户可以快速将音频文件迁移到规范化的目录结构中，提高音乐文件的组织性和可读性。
