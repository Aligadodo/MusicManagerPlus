# 测试计划和迭代清单

## 1. 测试计划概述

### 1.1 测试目标

- 验证新任务管理架构的功能完整性和正确性
- 确保前后端接口的稳定性和可靠性
- 验证任务执行流程的端到端功能
- 确保系统的性能和稳定性
- 验证异常处理和错误恢复机制

### 1.2 测试范围

#### 1.2.1 后端测试

- **单元测试**：各个服务类的功能测试
- **集成测试**：服务之间的集成测试
- **API测试**：RESTful API接口测试
- **任务执行流程测试**：完整的任务执行流程测试
- **性能测试**：系统性能和压力测试

#### 1.2.2 前端测试

- **组件测试**：各个组件的功能测试
- **页面测试**：页面的交互测试
- **API集成测试**：前后端API集成测试
- **WebSocket测试**：实时通信测试

#### 1.2.3 端到端测试

- **完整流程测试**：从创建任务到执行完成的完整流程
- **异常场景测试**：各种异常情况的处理
- **并发测试**：多任务并发执行测试

### 1.3 测试环境

- **开发环境**：本地开发环境
- **测试环境**：独立的测试环境
- **预发布环境**：模拟生产环境

### 1.4 测试工具

- **JUnit 5**：Java单元测试框架
- **Mockito**：Java Mock框架
- **TestContainers**：集成测试容器
- **Postman**：API测试工具
- **JMeter**：性能测试工具
- **Flutter Test**：Flutter测试框架
- **Integration Test**：Flutter集成测试

     7. 等待执行完成

   - 验证：检查执行结果

     5. 等待预览完成

     7. 等待执行完成（部分失败）
     8. 重试失败记录
     9. 等待重试完成
   - 预期：失败的记录被重试
   - 验证：检查重试结果

4. **testCancelTaskFlow**
   - 描述：测试任务取消流程
   - 步骤：
     1. 创建任务
     2. 开始扫描
     3. 立即取消任务
   - 预期：任务被取消
   - 验证：检查任务状态

5. **testMultipleExecutionFlow**
   - 描述：测试多次执行流程
   - 步骤：
     1. 创建任务
     2. 开始扫描
     3. 等待扫描完成
     4. 开始预览
     5. 等待预览完成
     6. 第一次执行
     7. 等待执行完成
     8. 第二次执行
     9. 等待执行完成
   - 预期：两次执行都成功
   - 验证：检查执行历史

## 6. 构建和启动规范

### 6.1 构建规范

- **后端构建**：使用项目根目录下的 `bin/build_dist_macos.sh` 脚本进行构建
- **前端构建**：使用 `bin/macos/deploy-frontend.sh` 脚本进行构建
- **构建环境**：确保使用 JDK 8 编译后端代码，避免使用更高版本的 JDK
- **渲染器设置**：前端构建时使用 `FLUTTER_WEB_RENDERER=html` 环境变量，避免加载 CanvasKit

### 6.2 启动规范

- **后端启动**：使用 `bin/macos/start-backend.sh` 脚本启动后端服务
- **前端启动**：使用 `bin/macos/start-frontend.sh` 脚本启动前端服务
- **一键启动**：使用 `bin/macos/start-all.sh` 脚本同时启动前后端服务
- **服务管理**：使用 `bin/macos/restart-backend.sh`、`bin/macos/restart-frontend.sh` 和 `bin/macos/restart-all.sh` 脚本重启服务

### 6.3 重要要求

1. **禁止手动命令**：在迭代过程中，所有构建和启动操作必须使用脚本完成，禁止手动执行构建和启动命令
2. **脚本维护**：确保脚本的可用性和正确性，如有问题及时修复
3. **环境一致性**：使用脚本确保所有开发人员使用相同的构建和启动环境
4. **版本控制**：脚本文件必须纳入版本控制系统，确保团队成员使用相同版本的脚本

### 6.4 脚本使用流程

1. **构建项目**：运行 `bin/build_dist_macos.sh` 脚本构建完整项目
2. **部署前端**：运行 `bin/macos/deploy-frontend.sh` 脚本部署前端应用
3. **启动服务**：运行 `bin/macos/start-all.sh` 脚本启动所有服务
4. **重启服务**：运行相应的重启脚本重启服务
5. **停止服务**：运行 `bin/macos/stop-all.sh` 脚本停止所有服务
