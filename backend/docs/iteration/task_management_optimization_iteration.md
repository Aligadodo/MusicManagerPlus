## 3. 技术实现细节

### 3.1 后端状态简化

**原始状态**：
- CREATED, SCANNING, SCANNED, PREVIEWING, PREVIEWED, EXECUTING, COMPLETED, FAILED, CANCELLED

**简化后状态**：
- CREATED, SCANNING, PREVIEWING, EXECUTING, COMPLETED, FAILED, CANCELLED

**状态流转**：
1. CREATED → SCANNING (开始扫描)
2. SCANNING → PREVIEWING (扫描完成)
3. PREVIEWING → EXECUTING (预览完成)
4. EXECUTING → COMPLETED (执行完成)
5. 任何状态 → FAILED (执行失败)
6. 任何状态 → CANCELLED (用户取消)

### 3.2 前端界面调整

**顶部按钮**：
- 只保留"预览"按钮
- 点击预览按钮生成新任务并切换到任务列表页面

**任务列表**：
- 操作按钮移至右上角
- 任务状态和时间信息以标签形式显示在任务名称右侧
- 任务操作按钮：执行、重新运行、终止、删除
