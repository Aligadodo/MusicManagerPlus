## 5. 已知问题

### 5.1 已修复问题

1. **问题**: 任务列表只能显示一个任务
   - **原因**: PipelineController在每次预览前调用clearAllTasks()
   - **修复**: 移除clearAllTasks()调用，使用TaskRegistry管理多任务
   - **状态**: ✅ 已修复

2. **问题**: 任务详情刷新失败
   - **原因**: TaskController.taskInfoToDetailMap方法中缺少null检查
   - **修复**: 添加null检查和错误处理
   - **状态**: ✅ 已修复

3. **问题**: 预览后任务不显示在列表中
   - **原因**: PipelineController未正确创建持久化任务记录
   - **修复**: 集成TaskService创建持久化任务
   - **状态**: ✅ 已修复
